# Gestión Digital de Información para NicaTrade International

## Objetivo

Organizar la información relacionada con una operación de importación desde México hacia Nicaragua, utilizando diferentes herramientas digitales para su creación, procesamiento, organización, colaboración, control y recuperación.

## Caso de estudio

*NicaTrade International* es una empresa nicaragüense dedicada a la importación y exportación de productos alimenticios y de consumo hacia diferentes mercados de Centroamérica. Este proyecto simula el trabajo del equipo de transformación digital encargado de mejorar la gestión de su información empresarial, tomando como caso una operación de importación México → Nicaragua.

## Herramientas utilizadas

- **Word** — Elaboración del informe ejecutivo de la operación.
- **Excel** — Procesamiento y análisis de los datos de importación.
- **PowerPoint** — Comunicación de resultados mediante una presentación.
- **Google Drive** — Organización del trabajo en equipo y colaboración.
- **GitHub** — Repositorio digital y registro de cambios del proyecto.
- **Simulación de gestión documental con Google Drive** — Representación de conceptos de un sistema tipo Alfresco Content Services (organización, control de acceso, recuperación de documentos).
